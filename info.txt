PROJECT CONTEXT

Framework layout:
  VIEW::Shape
    tensor shape descriptor
    dims[4], strides[4], rank, dtype

  VIEW::Math
    tensor object
    cpu pointer
    gpu pointer
    cpu/gpu offsets
    bytes
    count
    Shape layout

  HANDLER::Cpu
    CPU memory pool

  HANDLER::Cuda
    GPU memory pool

  HANDLER::IO
    binds Math to CPU/GPU memory
    copies host/device/device
    has helper copyHalfToCpuFloat(dst, src)
      src: GPU VIEW::F16 Math
      dst: CPU VIEW::FLOAT Math
      used for debugging / reading GPU half tensors on CPU

  HANDLER::File
    reads CSV
    reads images on CPU as uint8 / VIEW::CHAR
    stores images in NCHW layout
    copyImageToDevice converts CPU uint8 images to GPU half / VIEW::F16
    pullCpuImage returns CPU VIEW::CHAR
    pullGpuImage returns GPU VIEW::F16

  HANDLER::Workspace
    shared runtime context
    owns:
      IO reference
      File reference
      cudnnHandle_t
      cublasLtHandle_t
      cudaStream_t
      scratch pointer
      scratch size

    operators use:
      workspace.getStream()
      workspace.getCudnnHandle()
      workspace.getCublasLtHandle()
      workspace.getScratch(bytes)

DATA FLOW

  CSV paths
    -> File::readCsv()

  CPU images
    -> File::readImages()
    -> stored as uint8 / VIEW::CHAR
    -> shape: NCHW

  GPU images
    -> File::copyImageToDevice()
    -> uint8 converted to __half on GPU
    -> stored as VIEW::F16

  Batch pull
    -> File::pullGpuImage()
    -> returns GPU Math with dtype VIEW::F16

  CPU debug/readback
    -> IO::copyHalfToCpuFloat()
    -> converts GPU F16 Math to CPU FLOAT Math

NORMALIZE OPERATOR

  OPERATOR::Normalize
    input: GPU VIEW::F16 Math
    output: GPU VIEW::F16 Math
    operation: output = input / scalar
    default scalar: 255.0f

  Kernel design:
    vectorized with uint4
    each uint4 = 16 bytes = 8 half values
    each uint4 contains 4 half2 packs

  Helpers:
    helperKernelHalf2ToU32()
    helperKernelU32ToHalf2()
    helperKernelHalf2Norm()

  Kernel:
    normKernelByScalar(uint4 *OUT, const uint4 *IN, float scalar)

  Launch:
    uses workspace.getStream()

  Important:
    scalar is passed by value to kernel
    scalar does not need GPU memory

  Assumption:
    tensors are aligned to 256 bytes
    F16 storage is compatible with uint4 vectorized access
